# ADR 0002：模板采用结构化可视化拖拽编辑

状态：采纳并完成首期实现（2026-10-24）。

决策：模板以规范 JSON 对象为唯一源，YAML 只用于确定性导入/导出；字段和布局块使用稳定 ID。前端使用 React、原生 HTML5 拖拽和明确的“上移/下移”按钮实现三栏设计器，拖拽只修改受限布局树，支持组件插入、同层排序、跨允许容器移动、删除、字段属性编辑和撤销/重做；交互与视觉遵循 `docs/frontend-interaction.md` 的 `ikc-demo`/`WeKnora` 基线。未引入 `dnd-kit`，因为首期操作集可由浏览器原生拖拽与按钮共同覆盖，避免额外运行时依赖。服务端编译器是 Schema、预览和发布的唯一权威，画布不做任意 HTML/CSS、脚本或绝对定位。模板草稿以 `If-Match`/control_version CAS 保存，发布版本不可变，文档固定模板版本。

理由：结构化画布能直接生成响应式采编/阅读布局，和无障碍、移动端及服务端校验共享同一树模型；相比自由画布，显著降低任意样式、跨端偏差和安全风险。

代价：不支持 Canva 式自由摆放和任意视觉组件；原生拖拽需要自行维护落点、非法嵌套与视觉反馈，当前也没有 `dnd-kit` 那样的完整键盘拖拽体验，键盘用户改走上移/下移按钮。需要维护拖拽操作约束、YAML round-trip 测试和编辑器 E2E。若未来确需自由画布，应另立 ADR，并限定为导出静态布局，不与首期结构化模型混用。
