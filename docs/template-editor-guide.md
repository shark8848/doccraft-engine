# 模板编辑器使用指南

本指南适用于 DocCraft Engine 当前版本的可视化模板编辑器，覆盖模板创建、区块编排、字段配置、校验、预览、发布和 YAML 导入导出。

## 创建模板

1. 从左侧导航进入`模板`。
2. 点击页面右上角的`新建模板`。
3. 填写`模板名称`（必填，最多 200 个字符）和`说明`（最多 500 个字符）。
4. 点击`创建并编辑`，进入模板编辑器。

新模板自带一组可运行的示例骨架：

| 字段 ID | 类型 | 默认显示名 | 默认必填阶段 | 默认检索用途 |
|---|---|---|---|---|
| `title` | 单行文本 | 标题 | 提交、发布 | 标题 |
| `summary` | 长文本 | 摘要 | 提交、发布 | 摘要 |
| `body` | 富文本 | 正文 | 发布 | 全文 |

画布中预置了`文档内容`分组，并按顺序放入标题、摘要和正文三个区块。可以直接修改，也可以删除后重新编排。

## 认识编辑器

编辑器由顶部工具条和左、中、右三栏组成。

- 顶部：返回、模板名称、控制版本、已发布版本和未保存状态；`导入`、`导出`、`校验`、`保存`、`预览`、`发布`；以及撤销、重做按钮。
- 左侧：组件面板和字段列表。点击字段可打开字段编辑抽屉，点击`添加`可新建字段。
- 中间：结构化画布。区块可选中、拖动、上移、下移和删除。
- 右侧：选中区块时显示该区块和字段的属性；未选中区块时显示模板设置、检索字段和完整字段列表。

模板名称、说明或结构发生变化后，顶部会出现未保存状态点，并显示`有未保存改动`。未保存时返回列表，浏览器会要求确认。

## 编排区块

### 添加区块

从左侧点击或拖动以下组件：

| 组件 | 用途 | 主要内容 |
|---|---|---|
| 字段 | 一个表单输入控件 | 引用一个字段 |
| 富文本 | 正文编辑区 | 引用一个`richtext`字段 |
| 媒体 | 媒体上传或选择区 | 引用一个`asset`字段 |
| 分组 | 对相关内容分组 | 子区块容器，可设置分组标题 |
| 分栏 | 自适应多列布局 | 子区块容器 |
| 容器 | 纵向布局容器 | 子区块容器，无额外标题 |
| 说明 | 固定的辅助文字 | 不引用字段 |

点击组件时，插入位置取决于当前选中项：

- 未选中任何区块：追加到模板根布局末尾。
- 选中容器：追加到该容器末尾。
- 选中普通区块：插入到该区块之前。

也可以把组件拖到画布中的目标区块前。目标区块位于某个容器内时，新组件会插入该容器；需要把区块放进空容器时，先选中容器，再点击左侧组件最稳妥。

### 调整顺序和删除

- 选中区块后，使用区块右上角或右侧`结构`区域的上移、下移和删除按钮。
- 拖动区块左上角的拖动手柄，可改变同一容器内的顺序或移动到其他容器。
- 删除有子区块的容器前会二次确认；其子区块会一并删除。
- 删除区块时，只属于该区块、删除后不再被布局或检索配置引用的字段会自动清理。

### 分组中可放什么

分组可以直接包含：

- 字段、富文本、媒体和说明。
- 容器和分栏。

分组不能直接包含另一个分组。如果确实需要二级分组，先在分组中放入`容器`或`分栏`，再在容器或分栏中放入新的分组。

布局最大嵌套 6 层；所有容器至少要有一个子区块；根布局必须是纵向容器。把这些限制用于发布前校验，可避免把无效结构保存成版本。

## 编辑字段

字段可以在以下位置编辑：

- 左侧`字段`列表：点击字段名称。
- 右侧`字段`列表：点击字段行或编辑图标。
- 右侧`字段定义`：选中引用了字段的区块后直接修改。
- 左侧或右侧的`添加字段`按钮：新建后自动打开编辑抽屉。

字段编辑抽屉支持：

- `显示名称`：文档编辑器中展示的标签，最多 200 个字符。
- `字段 ID`：创建时生成，作为稳定标识，不可修改。
- `字段类型`：切换类型时会同步调整引用该字段的区块类型。
- `占位提示`和`帮助说明`：用于指导填写。
- `必填阶段`：可分别勾选草稿、提交和发布；未勾选的阶段不要求该字段有值。
- `选项`：仅单选字段显示。

### 字段类型

| 类型 | 文档编辑器中的控件 | 使用说明 |
|---|---|---|
| 单行文本 `string` | 单行输入框 | 标题、名称、短文本 |
| 长文本 `text` | 多行输入框 | 摘要、说明 |
| 富文本 `richtext` | 富文本编辑器 | 必须使用`富文本`区块 |
| 单选 `enum` | 下拉单选 | 必须配置至少一个选项 |
| 文本列表 `array` | 可输入多个标签 | 输入后回车添加一个值 |
| 数字 `number` | 数字输入框 | 只接受数字 |
| 开关 `boolean` | 开关 | 是/否状态 |
| 日期 `date` | 日期选择器 | 保存为 `YYYY-MM-DD` |
| 媒体资产 `asset` | 上传或选择媒体 | 必须使用`媒体`区块 |
| 对象 `object` | JSON 对象输入框 | 结构化键值数据 |

把字段切换为富文本或媒体资产时，引用它的区块会切换为对应类型；切换为其他类型时，区块会恢复为普通字段区块。修改类型后应重新校验并预览，确认已有内容仍符合预期。

### 配置单选选项

单选选项按行输入，每行格式为：

```text
值|显示名
```

例如：

```text
draft|草稿
published|已发布
archived|已归档
```

- 每行一个选项，可以连续输入多行。
- 只写值时，显示名与值相同。
- 值用于存储，显示名用于界面展示。
- 输入框失去焦点后会按规范格式整理。
- 切换到一个没有选项的字段为单选时，系统会自动补充`option_1|选项 1`。

## 配置检索字段

在画布空白处点击，取消区块选中后，右侧会显示`检索字段`：

- `标题`：必填，用于文档标题和搜索结果标题。
- `摘要`：可选，用于结果摘要和摘要匹配。
- `全文`：可选，用于全文检索。

如果模板包含可搜索的正文，建议把`全文`指向正文对应的富文本字段。未配置全文时，表格等非标题内容不会自动进入 Elasticsearch 的全文检索，搜索结果主要依赖标题和摘要。

## 在富文本中编辑表格

在文档编辑器的富文本工具栏中：

1. 点击表格图标，打开居中的`插入表格`弹窗。
2. 设置行数（1–20）和列数（1–10）。
3. 点击`插入`。首行会作为表头。
4. 光标放到表格内后，使用工具栏的增行、增列和删除表格图标。

表格操作使用图标按钮而不是文字按钮，悬停会显示说明：

- 表格图标：插入表格。
- 下方增行图标：在当前行后增加一行。
- 右侧增列图标：在当前列后增加一列。
- 垃圾桶图标：删除当前表格。

增行、增列和删除表格前，需要先把光标放到目标表格内，否则会提示`请先把光标放到表格内`。插入表格的尺寸设置使用项目内的居中弹窗，不使用浏览器原生输入框。

表格属于富文本正文内容。如果希望表格中的数据参与全文检索，请把该富文本字段配置为`全文`检索字段。

## 校验模板

点击顶部`校验`会把当前本地模板提交到服务端校验，但不会保存草稿。校验错误会集中显示在`校验结果`弹窗中。

常见诊断及处理方式：

| 提示 | 处理方式 |
|---|---|
| 字段不存在 | 在区块属性中重新选择有效字段 |
| 必须引用字段 | 为字段、富文本或媒体区块选择字段 |
| 容器至少需要一个子区块 | 添加子区块，或删除空容器 |
| 布局嵌套不能超过 6 层 | 减少容器和分栏嵌套 |
| 字段 ID 或 block ID 重复 | 检查 YAML 或复制后的结构，确保 ID 唯一 |
| 字段/区块 ID 格式不合法 | 使用小写字母开头、仅含小写字母、数字和下划线，长度 2–64 |
| 富文本或媒体类型不匹配 | 切换字段类型，或改用匹配的区块 |
| 标题字段不存在 | 在`检索字段`中选择标题字段 |
| enum 字段必须提供 options | 为单选字段补充选项 |
| 静态文本不能为空 | 填写说明文字，或删除说明区块 |

校验和发布时生成的字段 Schema 只包含布局或检索配置实际引用的字段。历史草稿中已经失去引用的孤儿字段仍可能保留在字段列表中，但不会参与文档内容的必填校验和类型校验；如不再需要，可手动删除。字段定义本身仍须合法，例如单选字段不能没有选项。

## 预览

点击`预览`可在`表单预览`和`阅读预览`之间切换：

- `表单预览`：查看文档编辑器中的字段顺序和布局。
- `阅读预览`：查看发布后的大致阅读顺序。

预览使用当前本地结构，不需要先保存。

## 保存和发布

### 保存草稿

点击`保存`提交当前草稿。保存使用控制版本进行并发保护，成功后更新控制版本并清除未保存状态。

如果模板已被其他会话更新，会出现`保存冲突`：

- `重新加载`：载入服务端最新版本，并丢弃本地改动。
- `保留本地`：关闭冲突弹窗，当前本地内容继续留在编辑器中。

### 发布版本

点击`发布`时：

1. 如果有未保存改动，先保存草稿。
2. 对服务端草稿执行完整校验。
3. 生成新的不可变模板版本，并更新已发布版本。

已创建的文档固定使用其创建时绑定的模板版本。之后发布新的模板版本，不会自动改写旧文档，也不会自动迁移旧文档的表单。

## 导入和导出 YAML

### 导入

点击顶部`导入`，可以选择 `.yaml`/`.yml` 文件或直接粘贴 YAML，然后点击`校验并导入`。

导入成功后内容只进入当前本地编辑器，仍是未保存状态，需要继续点击`保存`。导入失败时，错误会显示在`校验结果`中。

### 导出

点击顶部`导出`会下载服务端当前草稿的 YAML。尚未保存的本地改动不会包含在导出文件中；如需导出最新本地结构，请先保存。

一个最小模板示例：

```yaml
schemaVersion: 1
metadata:
  name: 产品说明
  description: 示例模板
fields:
  - id: title
    type: string
    label: 标题
    placeholder: 输入标题
    help: ""
    requiredAt: [submit, publish]
    options: []
  - id: body
    type: richtext
    label: 正文
    placeholder: ""
    help: ""
    requiredAt: [publish]
    options: []
layout:
  id: root
  kind: stack
  title: ""
  fieldId: null
  text: ""
  children:
    - id: sec_body
      kind: section
      title: 正文
      fieldId: null
      text: ""
      children:
        - id: slot_body
          kind: richText
          title: ""
          fieldId: body
          text: ""
          children: []
workflow:
  singleReview: true
indexing:
  titleField: title
  summaryField: ""
  fullTextField: body
```

YAML 顶层必须是对象，使用 `schemaVersion: 1`，不允许使用 YAML merge key（`<<`）。

## 常见问题

### 为什么字段删不掉？

字段仍被画布中的区块引用，或仍作为标题、摘要、全文检索字段。先移除对应区块或切换检索字段，再删除字段。标题检索字段必须先切换到其他字段后才能删除。

### 为什么删除区块后字段不见了？

删除区块时，系统会清理只被该区块引用、且不再被其他布局或检索配置使用的字段。这是为了避免留下无用字段。仍被其他区块或检索配置引用的字段会保留。

### 为什么字段列表里还显示旧字段？

历史草稿可能保留了已经失去布局和检索引用的孤儿字段。它们不会参与文档内容的必填和类型校验，但会继续显示在字段列表中。确认无用后手动删除即可。

### 为什么单选选项只能看到一个值？

选项需要一行一个。输入多行后失焦会自动整理；在输入过程中可以继续换行添加，不会覆盖第一项。

### 为什么表格里的文字搜不到？

检查右侧`检索字段`的`全文`是否指向包含该表格的富文本字段。未配置全文时，只有标题、摘要等已配置字段会进入搜索投影。

### 为什么发布新模板后旧文档没有变化？

文档绑定创建时使用的模板版本。新版本只影响之后创建的文档，不会自动改变已有文档的字段和布局。
