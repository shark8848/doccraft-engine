# 前端交互与视觉基线

> 状态：首期已实现（2026-10-24）。本文既是交互基线，也是当前实现与后续打磨项的对照清单；不要求跨框架复用 `ikc-demo`/`WeKnora` 的组件代码。

## 参考边界

| 参考 | 采纳内容 |
|---|---|
| `ikc-demo` | 左侧栏应用壳、品牌区、分组导航、CSS 变量主题、卡片/抽屉/页签/徽章、键盘焦点与图标按钮规范 |
| `WeKnora` | 浅色紧凑内容区、页头标题/说明/动作、筛选工具条 + 搜索、资源卡片网格、空状态/骨架屏、toast/确认/抽屉反馈 |

冲突时以“`ikc-demo` 的壳层与主题骨架 + `WeKnora` 的内容密度与列表交互”为准。DocCraft 使用 React + Ant Design 的 `ConfigProvider`/CSS 变量实现，不复制 `WeKnora` 的 Vue/TDesign 组件，也不在两套组件语言之间混搭。模板设计器使用原生 HTML5 拖拽，富文本使用 `contentEditable` 与显式 JSON AST 序列化，不依赖 `dnd-kit` 或 Tiptap。

## 应用骨架

- 左侧栏宽度 `clamp(200px, 15vw, 236px)`，可折叠为 68px；包含品牌、分组导航和底部主题/状态区，交互与 `ikc-demo` 对齐。
- 主区左右留白 22–26px，内容横向铺满，不设会阻止宽屏自适应的固定最大宽度；列表页自行限制卡片网格宽度。
- 页头采用“图标 + 标题 + 一行说明 + 右侧主/辅操作”，嵌套页面增加面包屑；页头动作不换行到错误位置。
- 列表页默认使用卡片网格；权限、审计、任务等密集管理页使用紧凑表格。模板设计器使用全高工作区，文档编辑器使用页面级三栏布局。

## 设计 Token

所有颜色、字号、间距、圆角、阴影和动画必须来自统一 token 文件，不在业务组件散落十六进制颜色。

```css
:root {
  --bg: #f5f7fa;
  --bg-panel: #ffffff;
  --bg-hover: #eef2f7;
  --border: #d8e0ea;
  --text: #1d2633;
  --text-dim: #5c6b7a;
  --accent: #07c05f;
  --accent-dim: #e9f8ec;
  --ok: #1f9d6a;
  --warn: #b8860b;
  --err: #d64545;
  --radius: 12px;
  --radius-sm: 8px;
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 20px;
  --space-6: 24px;
  --motion-fast: 150ms;
  --motion-base: 200ms;
  --text-xs: 11px;
  --text-sm: 12px;
  --text-md: 13px;
  --text-base: 14px;
  --text-lg: 15px;
  --text-xl: 16px;
  --text-2xl: 18px;
}
```

- 默认浅色、绿色品牌强调，对齐 `WeKnora` 当前界面；保留 `ikc-demo` 的深色、浅色、高对比、护眼绿四套主题切换能力，主题由 `data-theme` 驱动。
- 基础字号 14px，正文/控件 13–14px，辅助信息 11–12px，页标题 18–20px；字体栈与两套参考应用一致，中文优先 PingFang SC / Microsoft YaHei。
- 卡片圆角 12px，输入框和按钮圆角 8px；边框使用 1px 中性色，禁止厚重阴影和玻璃拟态。
- 动效 120–200ms，只用于 hover、展开、抽屉和拖拽落点；`prefers-reduced-motion` 下关闭非必要动画。

## 页面与组件

### 列表与搜索

- 页头下方依次放范围切换、筛选器和搜索框；范围切换使用紧凑 segmented tabs，搜索默认 260px 并靠右，小屏自动换行。
- 卡片网格使用 `repeat(auto-fill, minmax(min(100%, 260px), 1fr))`，间距 10–12px；卡片内边距 12px，最小高度 132px，标题单行省略、描述两行截断。
- 卡片 hover 只增强品牌色边框和极轻阴影，`:focus-visible` 显示 2px 品牌色焦点环；更多操作固定在右上角，点击卡片空白处进入详情。
- 首次加载显示与卡片结构一致的骨架屏；无数据使用统一空状态（圆形图标、标题、说明、主操作），搜索无结果提供清除按钮。

### 按钮与表单

- 每个区域只允许一个主按钮；次级操作用描边按钮，更多/关闭/拖动使用无边框图标按钮，图标 16px、点击区不小于 28–32px。
- 表单标签在上，控件 32–36px 高，辅助说明 11–12px，校验错误就地展示；简单编辑用抽屉或行内编辑，跨步骤/破坏性操作才用模态框。
- 危险操作使用红色文案和二次确认，确认按钮说明具体对象与后果；请求进行中禁用重复提交，短操作显示局部 loading，长任务显示进度和可恢复状态。
- 搜索与筛选当前保存在页面状态并显示结果计数；写入 URL、分页和排序状态持久化列为后续打磨项。

### 反馈与导航

- 成功/警告/错误使用顶部非阻塞 message；需要用户决策时使用 dialog；详情、属性、来源和编辑使用右侧 drawer，Esc/遮罩关闭。
- 状态用低饱和背景徽章表示，颜色只辅助语义，必须同时有文字或图标；错误信息包含可读说明，技术 traceId 放在次要位置。
- 页签用于切换整块内容，segmented 用于轻量取值/过滤；不要用 tab 代替表单选项。
- 所有图标按钮必须同时提供 `aria-label` 与 tooltip；hover 不是唯一反馈，键盘焦点必须可见。

## 模板设计器

- 顶部工具条：返回、模板名/版本、撤销/重做、校验、保存、预览、发布；未保存改动用强调色状态点，离开前确认。
- 左侧组件面板约 240px，中间画布在浅灰底上使用白色画布卡片，右侧属性面板约 300px；小于 1200px 时属性面板可折叠，小于 900px 时改为抽屉。
- 拖动时显示跟手浮层和目标落点线；可放置容器高亮 2px 品牌色，非法落点显示错误色并给出原因。选中块用 2px 描边和右上角操作条，不使用常驻粗边框。
- 字段、区块、富文本和媒体槽共享同一套卡片/图标语言；空画布提示“从左侧拖入区块”并提供键盘添加按钮。
- 首期画布提供当前草稿的表单预览；阅读/移动预览与画布内错误标记在后续补齐。校验错误由服务端返回 path，并在页头消息中提示。

## 响应式与可访问性

- 断点：1200px 收窄编辑侧栏，960px 折叠主导航，720px 单列列表并让工具条换行。
- 交互目标不小于 32px，文本和背景满足 WCAG AA；拖拽、菜单、页签、抽屉均支持键盘操作。首期结构化拖拽通过每区块的上移/下移按钮提供键盘等价路径。
- 颜色、位置或拖拽不能是唯一信息通道；拖拽失败、保存冲突和上传失败都要有文字说明。
- 中文为默认语言，文案使用动宾短语和统一术语（模板、版本、草稿、审核、发布），避免同一动作多种叫法。

## 验收

- 已检查 1440、1024、390px 三档截图；390px 下列表页和编辑器均无横向溢出。720px 中间档仍纳入后续视觉回归。
- Playwright 当前覆盖桌面/移动导航、模板编辑与撤销、预览、主题切换、检索进入文档和窄屏无横向溢出；筛选/空状态、抽屉编辑、保存冲突与消息提示的专项 E2E 列为后续项。
- 键盘 E2E 与 axe 自动扫描尚未落地，列为后续验收项；当前已有按钮 `aria-label` 和可见焦点样式。
- 组件评审逐项对照 `ikc-demo` 的壳层/主题与 `WeKnora` 的页头/工具条/卡片/空状态，不以“看起来差不多”代替截图记录。
